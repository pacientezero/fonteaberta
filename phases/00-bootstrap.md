# Phase 00 - Bootstrap

Status: completed

## Goal

Create the minimum git-tracked structure that can support the rest of the platform.

## In scope

- Initialize the repository layout.
- Keep the references and roadmap in version control.
- Define the phase order for future work.

## Out of scope

- Real data ingestion.
- Directus schema work.
- UI implementation.
- RAG or model wiring.

## Exit criteria

- Git repo initialized.
- Root README in place.
- Ignore rules in place.
- Phase plan in place.
- Local stack boots without manual adjustment.
