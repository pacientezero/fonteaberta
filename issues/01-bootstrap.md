# Issue 01 - Bootstrap the platform

Phase: 00-bootstrap

## Goal

Create the minimum git-tracked structure and local stack skeleton that can support the rest of the platform.

## Scope

- Initialize the repository layout.
- Keep the references and roadmap in version control.
- Define the phase order for future work.

## Out of scope

- Real data ingestion.
- Directus schema work.
- UI implementation.
- RAG or model wiring.

## Dependencies

- None.

## Acceptance criteria

- Git repository is initialized on a work branch.
- Root README exists.
- Ignore rules exist.
- Phase plan exists.
- Issue index exists.

## Notes

- This issue is the active starting point for the project.
